# Cách sử dụng

- 1, lần đầu đăng nhập Sentinel nội dung trống, phải có request truy cập tới instance microservice thì cấu hình mới xuất hiện
- 2, Sentinel đã được cải tiến sâu, hỗ trợ lưu bền vào Nacos
- 3, hiện tại chỉ kiểm soát đối với Gateway, các service khác không cần
